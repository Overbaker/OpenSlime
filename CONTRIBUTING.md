# Contributing to OpenSlime

1. Read [PRINCIPLES.md](PRINCIPLES.md). Changes that add per-turn context, routers or new agents need a measured reason.
2. Fork https://github.com/Overbaker/OpenSlime and branch from `main`.
3. Run the checks in [CLAUDE.md](CLAUDE.md#checks) before opening a pull request.
4. Describe what changed, why, and how you verified it. Update README.md, README.zh-CN.md and AGENTS.md when behaviour changes.

Upstream issues that are not specific to OpenSlime belong at https://github.com/fengshao1227/ccg-workflow.
